# NBA Four Factors

Companion code for the Northwestern MSDS thesis **"Temporal Modeling of Dean
Oliver's Four Factors: Benchmarking NBA Margin Predictions Against the Vegas
Closing Line"** (Mistarz, 2026, in submission).

A leak-free, walk-forward system that predicts NBA game margins across 25
test seasons (2001-02 through 2025-26) and holds every model to the hardest
public benchmark available: the Vegas closing line.

## Headline results

Margin MAE, identical rows, per-fold means over 25 test seasons:

| Model | Margin MAE |
|---|---|
| M0: preseason win-total seed | 10.165 |
| M1: + season-to-date four-factor differentials | 9.895 |
| M2: + schedule context (rest, travel, back-to-backs) | 9.866 |
| M3: + reliability-shrunk recent form | 9.852 |
| GRU over four-factor game sequences | 9.840 |
| Kalman filter on margin (1 state per team) | 9.789 |

On the Vegas-lined universe (2007-2025, 22,692 games): Kalman 9.970 vs the
closing line's 9.686. Valuing each night's pregame inactive reports with a
reliability-shrunk Game Score closes 27-33 percent of that remaining gap for
every base model tested (headline: 9.881, 31.5 percent closed).

## What the study found

Gains came from adding information, never from adding model complexity. A
one-dimensional Kalman filter beat every neural network tested. The GRU's
edge over the regression ladder was isolated by transplanting its learned
attention profile into the regression as a temporal ramp: temporal weighting
explains two-thirds of the like-for-like difference, with the remainder
within noise. Pregame inactive lists carry real point-spread information
(about -0.15 margin points per Game Score point listed out), largest for the
bases that know least. Era separation was tested repeatedly and always
rejected: one pooled 25-season fit wins.

## Architecture

```
ingestion            rate-limited NBA Stats fetchers, checkpointed and
                     resumable, vcrpy-recorded for tests
processed layers     per-season parquet (games, box scores, play-by-play,
                     inactives, rosters)
features             four-factor differentials, schedule context, shrunk
                     recent form, availability valuations, Vegas lines
models               regression ladder, Keras GRU/LSTM (Siamese sequences),
                     Kalman state-space filters, player-state filters
evaluation           expanding-window walk-forward, per-fold scoring,
                     identical-row comparisons, Vegas benchmarking
```

Every model is evaluated strictly walk-forward: fits use only seasons before
the test season, features use only games before the predicted game, and
early-season gaps blend to a preseason seed rather than peeking.

## Layout

- `nba_four_factors/` — package: api fetchers, storage, features, modeling,
  rnn, player_state
- `tests/` — pytest suite; network calls replayed from vcrpy cassettes
- `scripts/` — experiment and results scripts (each maps to a table or
  figure in the thesis)
- `notebooks/` — EDA as plain-python notebooks
- `data/` — gitignored; fully regenerated by the ingestion pipeline

## Setup

```bash
git clone https://github.com/mistmr7/nba-four-factors.git
cd nba-four-factors
uv sync
uv run pre-commit install
uv run pytest
```

Python 3.12 via [uv](https://docs.astral.sh/uv/). Linting and typing: ruff
and pyright, enforced by pre-commit.

## Data

No NBA or betting data is redistributed in this repository. The ingestion
pipeline rebuilds the data layers from public NBA Stats endpoints
(rate-limited, checkpointed); preseason win totals and closing lines come
from public archives and are fetched separately.
